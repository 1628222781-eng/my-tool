## 目标
- 减少告警整理与交接返工，而非替换操作系统。
- 工单侧助手不改变设备状态；演示工单仅为待审核草稿。

## 关键边界
- 告警需携带：采样时间、设备在线状态、当前处理人。
- 按「设备 + eventId」做事件幂等去重。
- 控制 / OTA / 联锁 / 停机不进模型权限；一例越权即停试点。
